Network icons (arbitrum, base, bnb, ethereum, optimism, plasma, polygon, solana .svg)
are the "branded" network icons of web3icons (@web3icons/core 4.0.58), by 0xa3k5,
https://github.com/0xa3k5/web3icons, MIT License. Copied unchanged except for one
removed class attribute.

qr-evm.svg and qr-solana.svg are generated by this project. Each encodes only the
receiving address text in src/lib/sponsor.ts (SPONSOR_WALLETS). After an address
changes, generate the code again and decode it to check it before release.
