# uapis 英美发音：本地直连验证

日期：2026-10-23。此文档记录本地验证；生产 PR 只包含已授权的 IPA 运行时快照和 uapis provider 代码，不包含本地研究审计产物、凭据或音频文件。

## 实现范围

- 所有录音请求都由 uapis 提供，不再请求有道音频服务。
- 词卡 UK 按钮直接请求 `accent=uk`；US 按钮直接请求 `accent=us`；每个显式按钮一次只创建一个对应口音的 audio。
- 普通无口音点击和短语/自动朗读优先设置中选择的英音或美音（默认美音），再尝试另一口音；两者都失败后使用优先匹配所选口音的系统英语语音回退。默认口音持久保存在设备上，并随既有账号设置同步。
- 请求使用完整清洗后的单词文本，不把 IPA 传给音频服务。
- 显式按钮不换另一口音、不回退通用录音或 SpeechSynthesis；媒体失败、启动超时或后续错误显示可见失败并允许同一按钮重试。
- 使用直接 `<audio src>`，没有 JavaScript `fetch()` 或 Blob：跨源 fetch 会遇到 CORS，而直接媒体元素可以加载音频元数据。不把任何 key 放入前端，也不轮换 key；服务端动态限流，客户端不做循环自动重试。

## 发布边界

IPA 运行时快照的公开再分发授权已由发布方确认；本 PR 不包含原始下载、完整 provenance、审计文件、书籍或任何用户提供的凭据。快照仍不是完整词典，也不代表独立语言学金标准；固定首读音不按上下文消歧。

uapis 是第三方音频服务。显式 UK/US 控件直接请求无 key 的公开媒体 URL，浏览器会把完整单词作为 `word` 查询参数发送给服务；请求频率由服务端动态防滥用限流控制，客户端不轮换 key 或自动高频重试。测试拦截音频并使用合成媒体，因此只能证明 URL 映射、播放生命周期、取消和错误提示，不能证明真实音质、口音听辨、长期可用性或服务条款。生产环境仍应监控第三方服务状态和 429 失败。

普通 generic 朗读按设置首选口音、另一口音顺序请求 uapis 音频，两者都失败后回退系统英语语音；本 PR 不新增音频下载包，也不请求有道音频。

## 默认口音与短语

设置新增默认发音选项，普通单词和完整短语跟随 UK/US 选择；显式音标按钮仍严格对应自己的标注。旧设置或无效值默认 US。按发布方补充的接口说明，支持常见英文单词与短语，长度不超过 64 个字符；超过此长度或缺少资源不保证有音频。

参考官方接口页：<https://uapis.cn/docs/api-reference/get-dictionary-audio>。本次读取的页面只写“英文单词”，短语支持说明由发布方补充。真实无 key 请求 `water` UK/US 均为 200 MP3 且字节不同；完整 `lantern seller` UK/US 均为 200 MP3，但两份字节相同，不能据此承诺每个短语都有不同的英美版本，也没有把返回成功当成人工听辨结论。短语不显示或伪造音标，在词性下方提供 UK/US 两个显式发音按钮，分别发送完整短语及对应口音；移除顶部通用按钮。两个显式按钮与单词 IPA 按钮一样，不换口音或回退系统语音。正文点击触发的短语自动朗读则跟随默认设置。
